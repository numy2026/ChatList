## 2. Основные функции и возможности Cursor

| Функция | Что делает | Как использовать (кратко) |
|---------|------------|----------------------------|
| **AI Completion** | Автодополнение кода в реальном времени, основано на GPT‑4/Claude. | Пишете часть кода → нажимаете `Ctrl+Space` (или `Tab`) → выбираете нужный вариант. |
| **Chat / Code‑assistant** | Интерактивный чат‑бот внутри IDE, отвечает на вопросы, генерирует фрагменты, объясняет ошибки. | Открываете панель Chat → пишете запрос («как реализовать OAuth2?»). |
| **Refactor** | Автоматический рефакторинг (разбиение функций, переименование, оптимизация). | Выделяете участок → `Cmd+R` → выбираете действие (Extract, Rename, Optimize). |
| **Fix Bugs** | AI анализирует ошибку, предлагает исправление и патч. | При появлении ошибки в терминале → выбираете «Fix» в подсказке. |
| **Generate Tests** | Создает unit‑/integration‑тесты к выбранному коду. | Выделяете функцию → `Ctrl+T` → выбираете тип тестов. |
| **Documentation** | Генерирует doc‑строки и README‑файлы. | Выделяете модуль → `Cmd+D` → выбираете «Generate docs». |
| **Git Integration** | Показ diff‑ов, авто‑коммиты, запросы PR, откаты. | Через боковую панель Git → используете AI‑подсказки для сообщений коммитов. |
| **Terminal** | Встроенный терминал с поддержкой AI‑команд (например, «run tests»). | Открываете терминал → пишете запрос в виде комментария (`# run tests`) → AI выполняет. |
| **Custom Prompts & Templates** | Пользовательские шаблоны запросов для повторяющихся задач. | Создаёте файл `prompt.yaml` → вызываете через команду `Ctrl+Shift+P`. |
| **Extensions** | Возможность подключать плагины (Python, Docker, Terraform). | Через Marketplace → устанавливаете нужный extension. |

## 5. Порядок освоения (пошаговый «Roadmap»)

### Шаг 0 – Подготовка среды
1. **Установить** Cursor (macOS/Windows/Linux).  
2. **Создать** бесплатный аккаунт (или воспользоваться пробным тарифом).  
3. **Настроить** Git (ssh‑ключи, глобальный `user.name/email`).  
4. **Установить** Python 3.11+ и Node 20 (через pyenv/nvm).  

### Шаг 1 – Овладеть базовым UI
- Открыть *Welcome*‑панель, переключить темы, настроить клавиатурные сокращения.  
- Протестировать *AI Completion* на простом `print("Hello")`.  

### Шаг 2 – Научиться задавать запросы
- Открыть *Chat*, написать «Explain what a Python decorator does».  
- Сохранить полезные ответы в **Snippets**.  

### Шаг 3 – Рефакторинг и исправление багов
- Возьмите готовый скрипт (например, «bubble sort»). Запустить **Fix** → увидеть патч → принять.  
- Выполнить **Extract Method** → увидеть новый файл.  

### Шаг 4 – Генерация тестов
- Выделить функцию `calc_average(nums)` → **Generate Tests** → открыть сгенерированный `test_calc_average.py`.  
- Запустить `pytest` в терминале Cursor → поправить непрошедший тест.  

### Шаг 5 – Интеграция с Git и CI
- Сделать коммит: в *Commit Message* написать запрос к AI «Summarize changes in 50 chars».  
- Создать репозиторий GitHub, подключить **GitHub Actions** workflow (пример из docs).  
- Через Cursor открыть *Pull Request* → добавить AI‑генерированное ревью.  

### Шаг 6 – Пользовательские промпты
- Создать `prompt.yaml`:
  ```yaml
  name: generate_fastapi_endpoint
  description: |
    Generate a FastAPI GET endpoint that returns a list of items.
  template: |
    from fastapi import APIRouter
    router = APIRouter()
    
    @router.get("{path}")
    async def get_items():
        return {response}
  ```
- Вызвать через `Ctrl+Shift+P → Run Prompt → generate_fastapi_endpoint`.  

### Шаг 7 – Мини‑проект (итоги)
- Планировать проект (требования, API, UI).  
- Делать каждый модуль с помощью AI: генерация кода, рефакторинг, тесты, документация.  
- Применять **Code Review**: запросить у AI «Find potential security issues».  

### Шаг 8 – Поддержка и развитие
- Подписаться на **Cursor Blog** и **newsletter**.  
- Участвовать в **Discord‑сообществе** (канал `#beginners`).  
- Периодически обновлять **Custom Prompt Library** и делиться в GitHub.

## 7. Советы «из первых рук»

| Совет | Почему полезен |
|-------|----------------|
| **Начинай с маленьких запросов** – «write a function that returns factorial». | Позволяет быстро увидеть ограничения модели и скорректировать запрос. |
| **Всегда проверяй сгенерированный код** – запускай тесты, линтеры. | AI может предложить «рабочий» код, но с потенциальными скрытыми багами. |
| **Не полагайся только на автодополнение** – использу́й *Chat* для объяснений и *Refactor* для чистого кода. | Комбинация функций дает более надёжный результат. |

| **Настраивай «temperature» и «max tokens»** в Settings → AI → Advanced. | При низкой temperature получаются более предсказуемые ответы; при высоких – креативные идеи. |
| **Регулярно обновляй Cursor** – разработчики часто добавляют новые плагины и улучшения. | База знаний растёт, а вы получаете новые возможности без усилий. |

Персональные данные — это любая информация, относящаяся к **непосредственно или косвенно определённому** физическому лицу (субъекту персональных данных). То есть, если по информации можно установить личность человека — это персональные данные.

### Основные примеры персональных данных (по российскому законодательству, в частности, ФЗ-152 «О персональных данных»):

#### 🔹 **Типичные персональные данные**:
- Фамилия, имя, отчество
- Дата и место рождения
- Адрес (включая регистрацию и фактическое проживание)
- Контактные данные: телефон, электронная почта, социальные сети
- Паспортные данные: серия, номер, дата выдачи, орган выдачи
- ИНН, СНИЛС
- Данные о семейном положении (например, брак, дети)
- Образование, профессия, место работы
- Фотографии, аудио- и видеозаписи (если человек на них виден/услышен)
- Биометрические данные (отпечатки пальцев, ДНК, лицо — если используются для идентификации)
- Данные о здоровье, медицинские заключения
- Данные о религиозных убеждениях, политических взглядах
- Данные о принадлежности к профсоюзам, общественным организациям
- Банковские реквизиты, данные о доходах
- Идентификаторы в онлайн-сервисах (логины, ID пользователей, если связаны с личностью)

#### 🔹 **Специальные категории персональных данных** (требуют особой защиты):
- Расовая или этническая принадлежность
- Политические взгляды
- Религиозные или философские убеждения
- Принадлежность к профсоюзам
- Состояние здоровья, инвалидность
- Биометрические данные (для идентификации)
- Данные о преступлениях и административных правонарушениях
- Данные о сексуальной жизни

> 💡 **Важно**: даже если данные кажутся «незначительными», например, просто "Иван" — если в контексте они позволяют идентифицировать конкретного человека (например, в маленькой компании или по IP-адресу), они могут считаться персональными.

---

### 🚫 Что **НЕ** является персональными данными:
- Анонимизированные данные (например, статистика, где нельзя установить личность)
- Данные юридических лиц (компаний, организаций)
- Данные, которые не позволяют установить личность (например, “мужчина 30 лет, живёт в Москве” – если нет других данных для идентификации)
- Имена в общих контекстах без связи с личностью (например, "Иванов" как фамилия в списке часто встречающихся фамилий)

---

### ✅ Практическое правило:
> **Если по данным можно установить, кто это — это персональные данные.**

Даже **IP-адрес**, **cookie**, **MAC-адрес**, **идентификаторы устройств** могут считаться персональными данными, если с их помощью можно идентифицировать человека (например, через данные провайдера или поведения в приложении).

---

### 📌 Законодательная база (РФ):
- **Федеральный закон № 152-ФЗ «О персональных данных»** — основной документ, регулирующий обработку ПД в России.

Если вы обрабатываете персональные данные (собираете, храните, передаёте, анализируете и т.д.), то вы — **оператор персональных данных** и обязаны соблюдать требования ФЗ-152.

## Cursor — AI‑ассистент для разработки кода  

**Cursor** — это современный инструмент, который встраивается в привычную среду разработки (VS Code, JetBrains IDE, Neovim и пр.) и позволяет писать, рефакторить, отлаживать и тестировать код при помощи крупной языковой модели (LLM). Проект разрабатывается компанией **Cursor Labs** (ранее назывался *Cursor AI*), а публичный релиз появился в середине 2023 года.

## 2. Техническая архитектура

| Компонент | Описание |
|-----------|----------|
| **LLM‑бэкенд** | По‑умолчанию Cursor использует **Claude 3.5 Sonnet** (Anthropic) и **GPT‑4o** (OpenAI) через собственные API‑прокси. Пользователь может переключаться между моделями и задавать «temperature», «max tokens» и пр. |
| **Cursor Server** (опционально) | Локальный процесс‑сервер, который кеширует запросы и хранит контекст проекта. Позволяет работать без постоянного соединения с интернетом (при наличии локального LLM, например, **Mistral‑7B‑Instruct**). |
| **IDE‑плагин** | Расширения для VS Code, JetBrains (IntelliJ, PyCharm, WebStorm), Neovim и Sublime Text. Плагин реализует UI‑чат, панель «Tasks», и функции «inline completion». |
| **База знаний** | Cursor индексирует файлы проекта (AST‑парсинг, импорт‑граф) и хранит их в векторных эмбеддингах (FAISS/SQLite). Это обеспечивает быстрый доступ к контексту без пересылки всего проекта в облако. |
| **Безопасность** | Данные передаются по HTTPS, в режиме «Enterprise» (платный план) можно полностью отключить отправку кода в облако и использовать только локальный LLM. Есть опция *“Do not share code”* для GDPR‑комплаенса. |

## 3. Как установить и настроить

### 3.1. Установка в VS Code (самый популярный путь)

1. Откройте **Extensions** → найдите *“Cursor – AI‑powered coding assistant”* и нажмите **Install**.  
2. После установки появится **Cursor**‑панель слева (иконка курсора).  
3. При первом запуске появится окно авторизации – введите **API‑ключ** от выбранного LLM (OpenAI, Anthropic и пр.) или используйте **“Free tier”**, который ограничен 30 минутами генерации в месяц.  
4. В `Settings → Extensions → Cursor` можно:
   - Выбрать модель по умолчанию (Claude‑3.5, GPT‑4o, Mistral).  
   - Настроить **temperature** (0‑1) и **max tokens**.  
   - Включить/отключить **Local Server** (для офлайн‑режима).  
   - Установить **папку проекта** для индексации (по умолчанию — текущий рабочий каталог).  

### 3.2. JetBrains IDE

1. В **Plugins Marketplace** ищете *Cursor* → **Install**.  
2. Перезапустите IDE.  
3. Аналогично VS Code – вводите ключ API в диалоговом окне `Cursor Settings`.  

### 3.3. Neovim

1. Установите **cursor.nvim** через ваш менеджер плагинов (packer, lazy.nvim).  
2. Добавьте в `init.lua`:

```lua
require('cursor').setup{
  api_key = os.getenv('CURSOR_API_KEY'),   -- желательно хранить в env
  model   = 'claude-3.5-sonnet',           -- или 'gpt-4o'
  local_server = true,                    -- включить локальный режим, если нужен
}
```

3. Команды: `:CursorChat`, `:CursorGenerate`, `:CursorRefactor`.

### 🔹 Основные характеристики Cursor

#### ✅ 1. **AI-первый подход**
Cursor позиционирует себя как **первая AI-native IDE**. Это означает, что весь интерфейс и функциональность построены вокруг ИИ-помощника, а не просто дополняются им, как в других редакторах (например, GitHub Copilot в VS Code).

- Поддерживает несколько передовых моделей ИИ.
- Можно выбирать, какую модель использовать для конкретной задачи.
- Модели работают **локально в чате и в редакторе** — вы можете задавать вопросы прямо в контексте вашего кода.

#### ✅ 3. **Команды по типу “/” (Slash Commands)**
Cursor вводит интуитивные команды, начинающиеся со слэша, что превращает редактор в "разговорный интерфейс":

| Команда | Действие |
|--------|----------|
| `/chat` | Открыть чат с ИИ, где можно обсудить код |
| `/edit` | Выделить код и попросить ИИ его изменить (например: “/edit сделай этот код более читаемым”) |
| `/test` | Сгенерировать юнит-тесты для выбранного кода |
| `/doc` | Создать документацию по выбранному фрагменту |
| `/explain` | Объяснить сложный код простым языком |
| `/find` | Найти и заменить по смыслу, а не по тексту |
| `/debug` | Найти и предложить исправление бага |

> Пример: выделяете 50 строк кода → пишете `/edit refactoring this to use async/await` → Cursor переписывает весь фрагмент за пару секунд.

#### ✅ 4. **Код-чтение и понимание проекта**
- Cursor **проанализирует всю вашу базу кода** и "поймёт" структуру проекта.

  _“Где у нас обрабатывается оплата?”_

  _“Какой API-эндпоинт вызывается при кнопке ‘Купить’?”_
- Это особенно ценно в больших и сложных проектах.

- Намного умнее, чем обычный IntelliSense.

#### ✅ 6. **Рефакторинг и исправление багов**

Температура кипения чистой воды при нормальном атмосферном давлении (1 атм, ≈ 101,3 кПа) составляет ≈ 100 °C.

* **В градусах Цельсия:** 100 °C  
* **В градусах Фаренгейта:** 212 °F  
* **В кельвинах:** 373,15 K  

Учтите, что эта величина меняется в зависимости от давления и высоты над уровнем моря:

| Высота над уровнем моря | Давление (кПа) | Температура кипения (°C) |
|--------------------------|----------------|--------------------------|
| Уровень моря (0 м)       | 101,3          | 100,0                    |
| 1000 м                    | ~89,9          | ≈ 96,7                   |
| 2000 м                    | ~79,5          | ≈ 93,4                   |
| 3000 м                    | ~70,1          | ≈ 90,1                   |

Также на точку кипения влияет наличие растворённых веществ (например, соли повышает её), а также чистота воды (при наличии примесей температура может слегка отклоняться). Если вам нужен более точный расчёт для конкретных условий (давление, состав), дайте дополнительные параметры — помогу рассчитать.
